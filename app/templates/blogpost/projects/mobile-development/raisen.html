Raisen is a personal project that simplifies travel planning and adds a creative twist. Built in Swift with Firebase for data, it does two things: generates personalized travel itineraries with the OpenAI API, and creates city-inspired collages with DALL·E. Like my other apps, it supports Google, Apple or email sign-in.

Sign-in without reinventing the wheel

Firebase Authentication handles logins, giving quick and secure access through familiar providers. As a solo developer, delegating auth and database logic let me focus on the core: understanding the user's input and integrating AI.

Itinerary generation

Enter a city and the number of days you will stay, and the app asks the OpenAI API for a personalized schedule: recommended spots, an efficient route between them, an estimate of how long to spend at each one, and images that showcase the city's highlights.

Preferences — city, days, personal constraints — are stored in Firestore, so a previous itinerary can be revisited or updated. The UI is deliberately minimal: the essential information about the trip is visible at a glance, without digging through menus.

Collage generator

Beyond planning, Raisen uses the DALL·E API to produce unique background images based on the chosen city — a collage that works as a wallpaper or can be shared. It was the most fun part to build: creative AI output driven by a single user input.

Settings

Users can change their login method, adjust notifications for future trips and log out or revoke access. Firebase keeps the data secure and preferences in sync across sessions.

Takeaways

I handled everything from UI/UX to API integrations, combining open-ended AI interactions with structured app components. Planned improvements include real-time data — traffic, local events — in the routing suggestions and more variety in the collage output.
